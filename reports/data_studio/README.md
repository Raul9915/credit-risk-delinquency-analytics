# Google Data Studio report

Interactive report built on the extracts in [`data/`](data/), which are generated by
`python -m src.pipeline`. The extracts are aggregated; they contain no applicant IDs.

> **Report link:** _add the public "view" link here after publishing._
> **PDF export:** `credit_risk_report.pdf` (add after publishing)

Menu names are given in English with the Spanish interface label in parentheses.

---

## 1. Data sources

For each CSV: **Create (Crear) → Data source (Fuente de datos) → File upload (Subir archivo)**,
upload the file and click **Connect (Conectar)**. Create one data source per file:

| Data source | File | Grain |
|---|---|---|
| `kpi` | `portfolio_kpis.csv` | segment type × segment value |
| `transitions` | `transition_matrix.csv` | credit type × from-state × to-state |
| `roll` | `roll_rates.csv` | credit type × from-state |
| `vintage` | `vintage_curves.csv` | cohort × credit type × months on book |
| `segments` | `risk_segments.csv` | risk band × contract × income × education (test set) |
| `metrics` | `model_metrics.csv` | model × split |
| `deciles` | `model_deciles.csv` | score decile (test set) |
| `cutoff` | `cutoff_strategy.csv` | approval rate 50–100% (test set) |
| `importance` | `feature_importance.csv` | top-20 features |

Upload limits: 100 MB per dataset, UTF-8. All extracts are well below that.

### Calculated fields (required)

Rates must be recomputed from counts. Averaging pre-computed rates gives wrong results when segments have different sizes. In the field editor, **Add a field (Añadir un campo)**:

| Data source | Field | Formula |
|---|---|---|
| `kpi`, `segments` | `Default rate` | `SUM(n_defaults) / SUM(n_clients)` → type *Percent* |
| `segments` | `Avg PD` | `SUM(sum_pd) / SUM(n_clients)` → type *Percent* |
| `transitions` | `Transition prob` | `SUM(n_transitions)` with **Percent of total** comparison, or keep `probability` with aggregation *Sum* when the chart is filtered to one credit type |

Set `probability`, `default_rate`, `pct_*`, `cumulative_default_rate`, `default_rate_approved` and `share_defaults_avoided` to type **Percent**.

### Approval-rate parameter

In `cutoff`: **Add a parameter (Añadir un parámetro)** → name `p_approval_rate`, type *Number (whole)*,
allowed values *range* 50–100, default 80. Then add the calculated field:

```
is_selected = CASE WHEN approval_rate_pct = p_approval_rate THEN 1 ELSE 0 END
```

## 2. Pages

Theme: **Theme and layout (Tema y diseño)** → simple light theme. One accent colour (`#2a78d6`) for single-series charts.

### Page 1 · Executive Summary
- Scorecards: applicants (`SUM(n_clients)` filtered to `segment_type = Overall`), `Default rate`, test AUC and Gini (`metrics`, filter `split = test`, `selected = 1`).
- Bar chart: `Default rate` by `segment_value`, with a drop-down control (*Control desplegable*) on `segment_type`.
- Text box: 3 key findings copied from `reports/results_summary.md`.

### Page 2 · Delinquency Dynamics
- **Pivot table with heatmap (Tabla dinámica con mapa de calor)** from `transitions`: rows `from_state`, columns `to_state`, metric `probability` (Sum). Sort rows and columns by `from_order` / `to_order`.
- Drop-down control on `credit_type` (default *All*).
- Bar chart from `roll`: `pct_roll_forward` by `from_state`.

### Page 3 · Vintage Cohorts
- Line chart from `vintage`: dimension `months_on_book`, breakdown `vintage_cohort`, metric `cumulative_default_rate` (Max).
- Filters: `is_reliable = 1`; drop-down control on `credit_type`.

### Page 4 · Risk Segmentation
- Bar chart: `Default rate` and `Avg PD` by `risk_band` (A → E).
- Table: `risk_band`, `name_contract_type`, `name_income_type`, clients, `Default rate`, with conditional formatting.
- Controls: `name_contract_type`, `name_income_type`, `name_education_type`.

### Page 5 · Model & Cut-off Strategy
- Line chart from `deciles`: `avg_pd` vs. `default_rate` by `decile` (calibration).
- Line chart from `cutoff`: `default_rate_approved` by `approval_rate_pct`.
- **Input control (Control de entrada / Control deslizante)** bound to `p_approval_rate`.
- Scorecards filtered by `is_selected = 1`: `default_rate_approved`, `share_defaults_avoided`, `n_approved`, `pd_threshold`.
- Note on the page: *"Estimated on a held-out test set of historical data."*
- Bar chart from `importance`: top features.

## 3. Publish

1. **Share (Compartir) → Manage access (Gestionar acceso)** → *Anyone with the link can view (Cualquier usuario con el enlace puede ver)*.
2. **File (Archivo) → Download as (Descargar como) → PDF**, save as `reports/data_studio/credit_risk_report.pdf`.
3. Take 2–3 screenshots (pages 2, 3 and 5) into `reports/data_studio/screenshots/` and paste the link at the top of this file and of the main README.

When the pipeline runs again, re-upload the CSVs: **Resource (Recurso) → Manage added data sources (Gestionar fuentes de datos añadidas) → Edit (Editar) → replace the file**.
